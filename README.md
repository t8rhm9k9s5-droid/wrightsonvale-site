# Wrightson & Vale — сайт wrightsonvale.ru

Публичная копия кода сайта мебельного ателье **Wrightson & Vale** (ГК «Фабрикант»), снятая с хостинга 19.11.2026 (сборка `site.js?v=v105`, `styles.css?v=v98`).

Статический сайт: `index.html`, `styles.css`, `fonts.css`, `site.js`, `sample.html`/`sample.js`, `privacy.html`, `consent.html`, `models/*.html` (28 моделей), `assets/` (изображения WEBP, шрифты Inter, Lora, Vale Roman).

Заявки с форм уходят в функцию Яндекс Облака и приходят на wv@wrightsonvale.ru.

Исходный репозиторий со скриптами сборки (`tools/models.cjs`, `tools/build.sh`) ведёт разработчик сайта; эта копия — для проверки кода.
